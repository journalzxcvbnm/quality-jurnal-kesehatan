CARA MEMBUKA DI VISUAL STUDIO CODE
1. Ekstrak file ZIP ini.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu pilih folder jurnal-kesehatan.
4. Pastikan folder files berisi brain-gym-review.pdf.
5. Instal ekstensi Live Server jika belum ada.
6. Klik kanan index.html > Open with Live Server.

TOMBOL PDF
- Tombol BACA PDF membuka file PDF terbaru di tab browser baru.
- Tombol Download PDF (jika tersedia pada halaman) mengunduh file PDF yang sama.
- Jika ingin mengganti artikel, timpa files/brain-gym-review.pdf dengan PDF baru dan pertahankan nama file tersebut.
